---
name: informe-de-fase
description: Redactar la entrega de una fase de WARRTS para Vito con el formato del prompt maestro.
---

Escribe en español sencillo, sin jerga, con este formato:

```
## Fase N: <nombre>, terminada

**Qué hay nuevo** (3 a 5 líneas)

**Cómo probarlo**
1. Paso exacto
2. Qué deberías ver

**Qué he comprobado yo**
- Pruebas: X de X pasan
- Partida automática: resultado
- Rendimiento: FPS con N unidades

**Decisiones que he tomado yo** (técnicas, se pueden cambiar)

**Preguntas para ti** (una por línea, con mi recomendación)

**Diferencias con el GDD** (con la sección)

**Siguiente fase:** nombre y qué incluye
```

Si te paras por un bloqueo, empieza por la pregunta concreta para Vito.
